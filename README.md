# LYNX GESTION

## Requisitos Previos
Para ejecutar esta aplicación, necesitas tener instalado **Node.js**.

1. Ve a [nodejs.org](https://nodejs.org/).
2. Descarga la versión **LTS** (Recommended for Most Users).
3. Instálalo siguiendo las instrucciones del asistente.
4. **IMPORTANTE**: Una vez instalado, cierra completamente VS Code (y cualquier terminal abierta) y vuelve a abrirlo para que se reconozcan los cambios.

## Cómo Iniciar

Una vez instalado Node.js:

1. Abre una terminal en esta carpeta.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre el link que aparece (ej. `http://localhost:5173`) en tu navegador.
